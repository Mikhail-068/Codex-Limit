# ADR-001: WPF и Codex App Server

Статус: принято и реализовано. Дата: 2026-09-04.

Задача: небольшой перемещаемый прибор поверх окон Windows, показывающий остаток подписочных лимитов Codex. Пользователь задал интервал 10 секунд.

Выбран WPF на .NET 8: прозрачное окно, векторная отрисовка, анимация и управление положением доступны без браузерного движка и сторонних UI-библиотек. Windows Forms NotifyIcon обеспечивает трей. Следствие: приложение работает только на Windows и требует Desktop Runtime.

Данные получает собственный дочерний Codex App Server по stdio через документированный `account/rateLimits/read`. Это позволяет использовать штатную авторизацию и не извлекать секреты из файлов или памяти настольного приложения. Модель не запускается. Следствие: нужен установленный Codex; совместимость протокола требует проверки после значимых обновлений.

Таймер опроса 10 секунд, тайм-аут одного RPC 8 секунд, независимая проверка свежести каждую секунду. При ошибках нет замены данных на выдуманный ноль или 100%. При прошедшей дате сброса требуется новый подтверждающий снимок.

Снимок лимитов хранится в памяти; настройки — в пользовательской локальной папке. Автозагрузка, установка и обновление за рамками первой версии.
